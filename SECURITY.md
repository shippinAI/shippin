# Security reporting

Shippin is in early development and has no production release or supported version
policy yet. Please do not disclose a suspected vulnerability in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/shippinAI/shippin/security/advisories/new)
to contact the maintainers. Include the affected commit or version, reproduction
steps, impact and any suggested mitigation. Avoid including credentials, production
data or sensitive personal information. Maintainer response times are not yet defined.

Ordinary bugs that do not disclose a security issue can be reported through GitHub
Issues. This policy does not represent a security certification or support guarantee.
